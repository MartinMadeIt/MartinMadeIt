# Cześć, jestem Marcin ! 👋

## Czym się zajmuję na codzień ?
  <ul>
    <li>Biorę udział, jako wsparcie merytoryczne, w tworzeniu projektów przez grafików</li>
    <li>Staram się wykonywać regularnie Code Review w miarę potrzeby</li>
    <li>Odpowiadam za dostępność stron Firmy. Testuję, wprowadzam zmiany zgodnie ze swoją wiedzą i doświadczeniem w tym zakresie, konsultuję ostatecznie wszystko ze specjalistą od WCAG</li>
    <li>Odpowiadam za dostarczanie nowych funkcjonalności dla Klientów</li>
    <li>Dążę do maksymalnej optymalizacji czasu pracy, poprzez tworzenie odpowienich narzędzi, które wykorzystuję na etapie wdrożeń</li>
    <li>W ostatnim czasie odpowiadałem za duży refaktor produktu, pod kątem Core Web Vitals, od przebudowania struktury projektu zaczynając, a kończąc na narzędziach do konwersji na WebP w locie</li>
    <li>Pisanie portali w oparciu o Wordpress</li>
    <li>Dostosowywanie pod kątem WCAG Wordpressowych stron Klienckich</li>
  </ul>

## Własny projekt
Oparty o Next, NodeJS, postgreSQL autorski projekt, łączący moje dziedziny wykształcenia - IT z Weterynarią.
